# إمبراطورية القنوات الأربع المستقلة (Autonomous 4-Channel Profit Media Empire)

منظومة إنتاج ونشر سينمائي مستقل 100% بتكلفة **$0.00 شهرياً**، مصممة خصيصاً للتوافق مع سياسات ربح يوتيوب (تحديث يوليو 2026) وربح محتوى فيسبوك في مصر، بدون أي تدخل يدوي لمدة سنتين فأكثر.

---

## القنوات الأربع المبرمجة في المنظومة

| الكود | اسم وهوية القناة | اللغة والجمهور | مصدر القوة والربح |
|---|---|---|---|
| `ch1_novels` | **مسرح الروايات الصوتية** | عربي (حلقات متسلسلة 16:9 + شورتس تشويقي) | تعدد أصوات تمثيلية + مطر وموسيقى سينمائية + ذاكرة تحفظ تسلسل الحلقات (تجمع 4000 ساعة مشاهدة بسرعة فائقة) |
| `ch2_en_mystery` | **Untold Science & Enigmas** | إنجليزي (أمريكا وبريطانيا وكندا) | أعلى عائد دولاري في يوتيوب (`$5–$10 RPM`) |
| `ch3_ar_history` | **أسرار الحضارات والخرائط** | عربي (الخليج ومصر) | محتوى وثائقي خالد (`Evergreen`) بعائد إعلاني خليجي مرتفع |
| `ch4_riddles` | **ألغاز المحقق — تحدي الـ 60 ثانية** | عربي تفاعلي | مصمم لتفجير التعليقات وفتح دعوة ربح فيسبوك (`Content Monetization`) بسرعة |

## خطوات التفعيل لمرة واحدة فقط (في 15 دقيقة وتنساها سنتين!)

1. أنشئ **4 قنوات يوتيوب** + **4 صفحات فيسبوك** بالأسماء أعلاه (يمكن إنشاؤها كلها تحت حساب جوجل وفيسبوك واحد أو حسابين).
2. افتح 4 حسابات مجانية على **[Zernio.com](https://zernio.com)** (الخطة المجانية للأبد بدون فيزا تعطي حسابين لكل إيميل = اربط في كل حساب **قناة يوتيوب + صفحة الفيسبوك المقابلة لها**).
3. انسخ مفتاح الـ API من كل حساب Zernio وأضفه في مستودع GitHub تحت **`Settings -> Secrets and variables -> Actions`**:
   - `GROQ_API_KEY`: مفتاح Groq المجاني الخاص بك.
   - `CH1_ZERNIO_KEY`: مفتاح Zernio الخاص بقناة الروايات.
   - `CH2_ZERNIO_KEY`: مفتاح Zernio الخاص بالقناة الإنجليزية.
   - `CH3_ZERNIO_KEY`: مفتاح Zernio الخاص بقناة التاريخ والحضارات.
   - `CH4_ZERNIO_KEY`: مفتاح Zernio الخاص بقناة ألغاز المحقق.
   - `AFFILIATE_COMMENT_FOOTER` *(اختياري)*: أي كود خصم أو رابط عمولة تريد إضافته تلقائياً في أول تعليق على جميع القنوات.

بمجرد إضافة المفتاح لأي قناة، ستبدأ بالنشر اليومي التلقائي فوراً وتلتزم تلقائياً بخيار الإفصاح عن الذكاء الاصطناعي (`containsSyntheticMedia: true`) لضمان القبول في برنامج شركاء يوتيوب.
