## 🔑 خطوة التفعيل الوحيدة (مرة واحدة فقط — مجاناً بدون فيزا)

تم بالفعل حفظ مفتاح الذكاء الاصطناعي والمزامنة الصوتية **`GROQ_API_KEY`** داخل مستودع GitHub.
لربط النشر التلقائي على يوتيوب وفيسبوك لكل قناة:

1. افتح حساب مجاني على **[Zernio.com](https://zernio.com)** (الخطة المجانية تتيح ربط **قناة يوتيوب + صفحة فيسبوك** بنشر غير محدود مدى الحياة مجاناً).
2. انسخ مفتاح الـ API وضعه في **Settings → Secrets and variables → Actions** بالأسماء التالية:
   - `CH1_ZERNIO_KEY`: للقناة المصرية الأولى.
   - `CH2_ZERNIO_KEY`: للقناة الإنجليزية الدولارية الأولى.
   - `CH3_ZERNIO_KEY` *(اختياري متى أردت توسعة الإمبراطورية)*.
   - `CH4_ZERNIO_KEY` *(اختياري متى أردت توسعة الإمبراطورية)*.
   - `PEXELS_API_KEY` *(اختياري — مفتاح مجاني من Pexels لزيادة تنوع مقاطع الطبخ والحرف لآلاف المقاطع)*.

> 💡 **تنبيه مهم بخصوص أرباح فيسبوك في مصر**: بمجرد بدء نزول الأرباح على صفحة فيسبوك، اربط حساب البنك المصري أو حساب استلام العوائد (Payout Account) خلال **أقل من 6 شهور** حتى لا تُلغى الأرباح المعلقة حسب لائحة Meta.
